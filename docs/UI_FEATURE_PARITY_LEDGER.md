## U01 — authoritative parity baseline (2026-10-18)

This section is the current index; dated notes below are historical implementation/verification checkpoints, not a competing “current” status. The ledger describes the source tree audited on 2026-10-18, whose configured app version is `0.1.125-beta` (version code `129`) and whose last committed parent is `fc96e69`. The worktree already contains extensive uncommitted changes, so this is a source anchor—not a reproducible APK or a claim that commit `fc96e69` contains the audited tree. No build or test task was run for this U01 update.

**Acceptance rule:** source presence or a passing unit test alone does not make a feature accepted. A journey is `Accepted` only when (1) the owner and all user-visible entry/actions are mapped, (2) applicable state, failure and recovery branches have executable coverage, (3) remote navigation is exercised through the production route, and (4) the version/device-tagged golden capture and its acceptance evidence are recorded. `Partial` means source or some regression evidence exists but one or more gates are open. `Unverified` means no current evidence. No J01–J14 journey is accepted by this audit. Historical test totals and device results below disagree; they remain useful as dated notes, but **there is no canonical current coverage/test total** until a single run is stored with commit, command and raw report artifacts. Do not infer a current pass by selecting or summing the largest historical number.

## Cross-cutting contracts

- **Identity:** all cards and commands carry the selected canonical content identity; provider IDs stay at adapters.
- **Focus and Back:** the shell owns navigation/back precedence; screens restore canonical item identity, not a stale row index or detached requester. Scrollable rails keep their focus frame at the pivot while content scrolls; only non-scrollable or end-clamped finite rails move the frame to the selected card.
- **Motion:** shared geometry and retargetable motion are common across shelves; no focus-only size jump. System/focus timings live in `SaabMotion` where they are shared.
- **Artwork:** prefetch and display use the same cache identity; retain the current drawable during refresh and use initials only for absent/failed artwork.
- **Fixtures:** `FeatureFixture`/`OfflineAppFixture` reject unexpected network calls. Journey fixtures must specify movie/series identity, episode, watched/list state, delayed metadata and failure state explicitly.
- **Performance:** emulator and unit results are not physical-TV evidence. Release-build traces must include low-memory and modern TV reference devices.
