## Test recipe key

- **L:** logic boundaries, valid/invalid/empty inputs, all decisions, deterministic output and no mutation.
- **V:** initial/loading/success/error states, async cancellation and stale response, profile isolation, exact persistence/events, repeat actions, lifecycle cancellation.
- **S:** request/response fixtures, cache hit/miss/expiry, HTTP/parse/timeout failure, cancellation, concurrency, retry limits and redaction.
- **O:** lifecycle, saved-state/recreation, navigation/back/focus transitions, permission/activity callbacks, dependency failures and cleanup.
- **P:** load/prepared/buffering/ready/error/end/release states, source/track controls, progress persistence, cancellation, render handoff and bounded resources; real device qualification separately.
- **U:** real Compose rendering and semantics, click/long-press/D-pad, state-driven controls, disabled/empty/error states, focus restoration, scroll, dialog/back and recomposition.
- **R:** Room/storage roundtrips, transactions/migrations, ordering, profile isolation, missing rows, concurrency and failures.
- **D:** serialization/defaults/normalization and meaningful compatibility contracts.
